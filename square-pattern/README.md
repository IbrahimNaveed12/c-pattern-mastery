# Square Pattern

This C program prints a square made of asterisks. The square has 5 rows and 5 columns.

## Loop Logic

- The outer `for` loop controls the rows.
- The inner `for` loop prints 5 asterisks in each row.
- A newline is printed after the inner loop finishes.

## Important Variables

- `row` counts from 0 to 4 and controls the rows.
- `column` counts from 0 to 4 and controls the asterisks in each row.

## Example Output

```text
*****
*****
*****
*****
*****
```
